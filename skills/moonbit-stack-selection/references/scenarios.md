# MoonBit 场景总表

快照 2026-11-05｜场景按分组排列。

每个场景一份索引页 `references/<id>.md`：完整方案全量 + 基础库按推荐次序列出；基础库较多的场景另有 `<id>-libs.md` 全量分册。本表只用来定位 id。

在线版单场景页：`https://moonbit-ecosystem-index.pages.dev/#/s/<id>`（如 `#/s/gui`）。站点是前端渲染的，直接抓页面拿不到数据；纯文本可直接取 https://raw.githubusercontent.com/lb091188/moonbit-ecosystem-index/main/skills/moonbit-stack-selection/references/<id>.md。

「完整方案」= 能当骨架、替你作决定的库；「基础库」= 只提供单点能力。场景内序号是推荐次序，不是下载量。
