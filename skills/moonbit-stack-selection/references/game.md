# 游戏引擎 / ECS（`game`）

*Game Engines / ECS*

> 快照 2026-11-05｜在线版 <https://moonbit-ecosystem-index.pages.dev/#/s/game>

游戏引擎、ECS 架构、程序化生成、游戏后端。

## 完整方案 · 可作骨架

1. **`Milky2018/selene`** v0.39.1
   基于 ECS 架构的游戏引擎，实体、组件与系统分层明确，适用于逻辑复杂且持续扩展的项目。
   <https://mooncakes.io/docs/Milky2018/selene>

2. **`mizchi/kagura`** v0.6.0
   2D 游戏引擎，参照 Ebiten 设计，提供游戏循环与精灵绘制，适用于中小规模项目。
   <https://mooncakes.io/docs/mizchi/kagura>

3. **`sssssurf/abyssal_chord`** v0.1.0
   卡牌对战专用引擎，内置回合、牌库与结算流程，附带命令行示例。
   <https://mooncakes.io/docs/sssssurf/abyssal_chord>

4. **`sacckey/moon8bit`** v0.1.0
   复古风格 2D 引擎，资源以文本描述，运行时具备确定性，适用于快速迭代与自动化生成。
   <https://mooncakes.io/docs/sacckey/moon8bit>

5. **`firefly/firefly`** v0.10.0
   Firefly Zero 掌机的游戏 SDK，仅面向该硬件平台，不适用于通用桌面环境。
   <https://mooncakes.io/docs/firefly/firefly>

6. **`sennenki/reisen`** v0.3.2
   视觉小说引擎，以剧本、立绘与分支组织内容，不适用于通用游戏开发。
   <https://mooncakes.io/docs/sennenki/reisen>
