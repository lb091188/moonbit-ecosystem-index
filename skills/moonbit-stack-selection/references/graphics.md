# 图形 / 图表 / 渲染（`graphics`）

*Graphics / Charts / Rendering*

> 快照 2026-11-05｜在线版 <https://moonbit-ecosystem-index.pages.dev/#/s/graphics>

矢量图形、SVG、场景图、图表与图形布局、绘图原语。

## 完整方案 · 可作骨架

**无。** 该场景没有骨架级实现，只能用基础库组合。
